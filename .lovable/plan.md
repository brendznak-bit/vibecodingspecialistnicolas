# Сокращение расстояния между секциями лендинга

## Цель
Уменьшить вертикальные отступы между секциями на лендинге, сохранив читаемость и акценты. Остальные стили, контент и компоненты не меняются.

## Что изменится

Будут отредактированы только вертикальные padding-секции в пяти landing-компонентах:

```text
Hero         src/components/landing/Hero.tsx
Services     src/components/landing/Services.tsx
Cases        src/components/landing/Cases.tsx
Process      src/components/landing/Process.tsx
ContactCta   src/components/landing/ContactCta.tsx
```

### Текущие и новые значения

| Секция | Текущие отступы | Новые отступы |
|--------|-----------------|---------------|
| Hero (внутренний контейнер) | `pb-12 pt-14 md:pb-24 md:pt-24` | `pb-10 pt-12 md:pb-16 md:pt-20` |
| Services | `py-11 md:py-20` | `py-9 md:py-14` |
| Cases | `py-11 md:py-20` | `py-9 md:py-14` |
| Process | `py-11 md:py-20` | `py-9 md:py-14` |
| ContactCta | `pb-14 pt-11 md:pb-24 md:pt-20` | `pb-12 pt-9 md:pb-16 md:pt-14` |

Сокращение примерно на 25–35% на десктопе и на 15–20% на мобильном, чтобы страница не казалась распылённой.

## Что не тронется

- Цвета, типографика, тени, радиусы, градиенты.
- Содержимое карточек, тексты, иконки, CTA.
- Шапка, футер, мобильное меню.
- Мета-теги и структура `src/routes/index.tsx`.

## Проверка

После правок запустится сборка проекта и, при необходимости, визуальная проверка через скриншот Hero/секций, чтобы убедиться, что отступы уменьшились равномерно и страница не выглядит «прилипшей».
